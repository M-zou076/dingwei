# 第一阶段人流服务

本服务只接收用户主动授权后的匿名定位，不生成模拟人数，不保存历史轨迹。某用户超过 3 分钟未上报会自动从实时人数中移除。

## 启动

电脑安装 Node.js 后，在本目录运行：

```powershell
node server.js
```

手机与电脑连接同一个 Wi-Fi，在 App 的“服务器”中填写：

```text
http://电脑的局域网IP:8787
```

例如 `http://192.168.1.8:8787`。Windows 防火墙首次询问时允许“专用网络”。

## 第二阶段地图校准

服务启动后，在电脑浏览器打开：

```text
http://127.0.0.1:8787/admin
```

管理口令位于 `admin-token.txt`。选择学校后，填写实测的百度 `BD-09` 经纬度，再点击地图图片中的同一地点并保存。至少需要 3 个不在同一直线上的控制点，建议采集 6–10 个并覆盖校园四周。

也可以在 Android App 中操作：先在室外“仅定位一次”，精度达到 30 米以内后点击“校准采点”，再点击图片中的对应地标。保存后手机刷新学校配置，即刻使用新的多点映射。

## 第三阶段天气与出行推荐

服务端会从 Open-Meteo 获取学校所在区域的真实天气，缓存 10 分钟，并与最近 3 分钟的真实人流结合。App 可选择“上课、学习、运动、吃饭、散步”，分别获得出行建议。

天气请求失败时会显示“天气数据暂不可用”，不会生成模拟天气。电脑需要能够访问 `https://api.open-meteo.com`。

## 增加其他学校

可以直接在校准网页底部上传 PNG/JPG 地图并创建学校，也可以手动把图片放进 `maps` 并编辑 `schools.json`。App 刷新学校列表后即可切换，无须重新打包 APK。

第一阶段采用经纬度矩形边界映射到图片。正式上线前应采集校园四角或多个控制点，完成更精确的地图配准。
